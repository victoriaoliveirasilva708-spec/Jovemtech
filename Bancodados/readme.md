SISTEMA DE BANCO DE DADOS

Escala e Solicitações para gerenciamento de funcionários.

# Modelagem e Implementação
Banco de dados relacional desenvolvido para gerenciar empresas, funcionários, escalas de trabalho, registros de ponto, benefícios e solicitações (férias, trocas e banco de horas).

# Tecnologias Utilizadas
- Modelagem: brModelo Web (BRMW)
- Banco de Dados (SGBD):PostgreSQL (hospedado no Supabase)

# Estrutura do da pasta do projeto (./Bancodados)
- ./tabelas: Script de criação das tabelas, chaves primárias (`PK`) e estrangeiras (`FK`).
- ./teste: Dados fictícios para testes.
- ./modelologico: Modelo logico feito no BRMW.
- ./diagramaconceito: Modelo conceitual do banco de dados também feito no BRMW.
- ./esquemasupabase: Print do visualizador de esquema no Supabase.
